# LocalSentry – downloads

LocalSentry turns a phone, tablet or computer into a camera you watch live
from another device on the same Wi-Fi. Encrypted, no cloud, no accounts.

**Website and downloads:** https://localsentry.app

This repository holds the released app files only (no source code). Every
version is under [Releases](../../releases); the latest files are always at:

- Android (most phones): `releases/latest/download/LocalSentry-android-arm64.apk`
- Android (all processors): `releases/latest/download/LocalSentry-android.apk`
- Linux (x86_64): `releases/latest/download/LocalSentry-linux-x64.tar.gz`

## Questions and bugs

Use [Issues](../../issues) to report a bug or suggest something. For a
security problem, please e-mail kontakt@localsentry.app instead of opening
a public issue.
