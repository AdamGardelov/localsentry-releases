# LocalSentry

LocalSentry turns a phone, tablet or computer into a camera you watch live
from another device on the same Wi-Fi. Encrypted, no cloud, no accounts.

**Website:** https://localsentry.app

LocalSentry for Android and iPhone is coming to Google Play and the App
Store. This repository holds no app files and no source code; it is the
public place for questions, bug reports and release notes.

## Questions and bugs

Use [Issues](../../issues) to report a bug and [Discussions](../../discussions)
to suggest something. For a security problem, please e-mail
kontakt@localsentry.app instead of opening a public issue.
